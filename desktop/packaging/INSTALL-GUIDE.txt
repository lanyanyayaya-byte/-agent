KnowledgeAgent macOS 安装引导（P8.2 测试安装包）
================================================

一、安装步骤
1. 在当前挂载的磁盘映像（DMG）窗口中，将「KnowledgeAgent.app」拖入右侧的「Applications」（应用程序）文件夹。
2. 打开 Finder →「应用程序」（Applications），双击「KnowledgeAgent」即可启动。
3. 启动后可在 Dock 栏右键点击「KnowledgeAgent」→「选项」→「在程序坞中保留」，固定到 Dock。
4. 确认应用正常启动后，可在 Finder 中推出（卸载）本 DMG 磁盘映像。

二、运行环境说明
- 本应用已内置完整的 Python 3.12 运行时与后端 Sidecar 组件。
- 用户无需安装 Python、Node.js、Rust 或使用终端命令行。

三、签名与测试包声明
- 本安装包为 P8.2 阶段的本地测试安装包，当前使用 macOS Ad-hoc 签名（signingIdentity: "-"）。
- 本测试安装包尚未执行 P8.3 的 Apple Developer ID 正式签名与 Apple Notary 公证，不得视为已通过 Gatekeeper 正式公证发行验收。
